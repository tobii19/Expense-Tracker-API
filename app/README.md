# Expense Tracker API

A FastAPI-based Expense Tracker REST API with JWT Authentication, Email OTP Verification, Password Reset, PostgreSQL, SQLAlchemy, Alembic, Dashboard Analytics, Reporting, and Excel Export.

## Features

- JWT Authentication
- Email OTP Verification
- Forgot Password & Reset Password
- Expense CRUD Operations
- Dashboard Analytics
- Monthly Reports
- Excel Export
- Pagination
- PostgreSQL
- SQLAlchemy ORM
- Alembic Migrations
- SMTP Email Integration

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT
- OpenPyXL
- SMTP
